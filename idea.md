# Product idea

A website for sending files through temporary links. A sender uploads one or more files, copies a single link, and shares it with whoever needs the files. The sender can protect the files with a password. Both the sender and the recipient can use the site without an account.

## How a transfer works

1. The sender selects one or more files, optionally adds a password, and sees the upload progress.
2. When the upload finishes, the site shows a link the sender can copy and share.
3. The recipient opens the link and enters the password if one was set. They can download files individually or download the whole set as a ZIP.
4. Guest files are available for 24 hours after upload. The sender can delete a file sooner. When a file expires or is deleted, the link stops providing access to that file.

## Shared pools

The first version focuses on guest transfers. A later version would add pools for groups that exchange files regularly. A pool is an invite-only space for up to seven people. Members can upload temporary files and download files shared by others in the pool. They can set aside part of their personal upload and storage allowances for the group to use.

For example, a student can send a set of slides and notes to a classmate with one link. A project group can use a pool to exchange updated files in the same place over time.
